| [**prompt-symbols**](https://github.com/nihitdev/prompt-symbols)           | Symbols and glyphs for terminal prompts                                      |
| [**nerd-font-glyphs**](https://github.com/nihitdev/nerd-font-glyphs)       | Curated Nerd Font glyph reference                                            |
